## Why I Built This

Most portfolios look the same. I wanted mine to be different—simple but memorable, minimal but meaningful. Every line of code serves a purpose. Every design choice tells part of my story.

## Tech Stack

```
HTML5  →  Structure
CSS3   →  Style (Poppins font, responsive design)
JS     →  Interactions (smooth scrolling, mobile menu)
```

That's it. Simple, fast, and fully responsive.

## Get Started

```bash
# Clone it
git clone https://github.com/ojas235767/ojas-portfolio.git

# Open it
cd ojas-portfolio

# View it (double-click index.html or use a local server)
python -m http.server 8000
```

Then visit `http://localhost:8000`

## Customize It

**Change content:** Edit `index.html`

Want to connect the contact form? Integrate Formspree, EmailJS, or your backend.
